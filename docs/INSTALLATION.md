# Installation Guide

**AutoQuad Remesher** is packaged as an official Blender Extension for **Blender 4.2 LTS and newer** (including Blender 5.0 and 5.2+).

---

## Installing via Blender Extensions Interface (Recommended)

1. Download the release archive: `autoquad_remesher-1.1.0.zip`.
2. Launch Blender 4.2+.
3. Open **Edit > Preferences**.
4. Select the **Get Extensions** or **Add-ons** section.
5. In the top-right corner, click the dropdown chevron **(∨)** next to the search bar.
6. Select **Install from Disk...**
7. Navigate to and select `autoquad_remesher-1.1.0.zip`.
8. Ensure **AutoQuad Remesher** is enabled.
9. In the 3D Viewport, press **N** to open the sidebar and click the **AutoQuad** tab.

---

## Uninstalling

1. Open **Edit > Preferences > Extensions / Add-ons**.
2. Search for `AutoQuad Remesher`.
3. Click the dropdown arrow next to the entry and select **Uninstall** (or disable the checkbox).
